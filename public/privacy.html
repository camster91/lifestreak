Privacy Policy — LifeStreak

Effective Date: May 24, 2026

Developer: Ashbi Design (cameron@ashbi.ca)

Summary

LifeStreak is a private, local-first habit and goal tracker. Ashbi Design does not receive your habit records, notes, service records, reading records, goals, or settings.

Data Collection

LifeStreak does not collect, sell, or share personal information with the developer for analytics or advertising. No account, analytics, tracking, advertising, crash reporting, or data-collecting third-party SDKs are required.

Data Storage

Your progress, settings, habits, notes, service hours, and reading list are stored locally on your device and are not uploaded by default. We cannot access or restore them.

Optional network actions

Opening an allowlisted external resource sends normal browser request metadata to that website. Collections settings can also optionally test a local or Ollama Cloud endpoint. This is disabled by default and requires an inline confirmation identifying the destination and payload before transmission.

The connection test sends only the selected model, fixed connectivity-test text, and an optional session-only API key to the user-selected Ollama destination. It does not send habits, notes, service, reading, goal, or memory records. The destination provider's privacy terms apply. Disabling Ollama clears the session credential; keys are not stored in backups or local storage.

Permissions

LifeStreak may request local notification permission for reminders. This permission is optional and can be disabled in device settings.

Data Export

You can export your data from Settings as a JSON file. You control where the exported file is saved or shared.

Contact

Questions about this policy can be sent to cameron@ashbi.ca.

Changes

Changes to this policy will be posted within the app and on this page.
