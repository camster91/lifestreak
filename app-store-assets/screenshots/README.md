# Draft screenshot assets

These PNGs were captured from the deployed LifeStreak web app at
`https://lifestreak.ashbi.ca` using Chromium at mobile CSS viewports and a 3x
device scale factor:

- `android/`: 1080×1920 output (360×640 CSS viewport)
- `ios/`: 1290×2796 output (430×932 CSS viewport)

They are draft browser captures for store-listing preparation. They do not
prove physical Android, iOS Simulator, or iOS device QA, and they have not
been submitted to either store.
